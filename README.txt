RahDas Bookshelf - installable app (PWA)
=======================================

1. Put this whole folder on any free HTTPS web host (see the steps given in chat; Netlify or GitHub Pages work).
2. Open the site on your phone.
3. First time only, the app asks for two things:
   - Web app URL  (Apps Script > Deploy > Manage deployments > copy the URL ending in /exec)
   - Access key   (Google Sheet > RahDas Bookshelf > Show app access key)
4. iPhone: Share > Add to Home Screen.   Android: menu > Install app.

The Apps Script deployment must be: Execute as = Me, Who has access = Anyone.
(The access key is what keeps strangers out.)
